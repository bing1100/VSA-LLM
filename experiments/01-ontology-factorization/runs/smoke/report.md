## Interpretation

The strict held-out recipes contain only `(role, value)` atomics observed in training, but no held-out target row enters the loss. Typed HRR therefore demonstrates the intended **compositional-disjoint transfer** in this controlled teacher world.

An earlier diagnostic run incorrectly assigned disjoint value-ID ranges to roles. The bag baseline then inferred role from value identity and nearly tied typed HRR (0.893 vs 0.897). The corrected experiment reuses one value vocabulary in every role; this is now a required control-design invariant.

This gate advances experiment 01 from implementation bootstrap to the real matrix-only milestone. It does **not** advance experiment 02: synthetic data are generated by an HRR teacher, no WordNet graph or real host embedding is present, and no behavioral/locality endpoint has been measured.
