## 2. The routers (the pre-registered questions)

**Decision rule** ("routing solved" iff the best realistic routed pipeline is within 0.05 of labelled type-prior
recall on property): **T4 solved** (size rule, +0.007 [−0.003, +0.016]); **T5 not solved** (best router pipeline
`lex`, −0.222\*). Both as predicted.

**Primaries:**
- Paraphrase demonstrations (`fewshot-para − fewshot`, gold frames): T4 −0.007 (n.s.), **T5 −0.011\***. Router
  accuracy on T5 0.36 → 0.40. The prediction (≥ +0.15 on T5) **failed**: these hosts do not generalise relation
  choice across question wordings, whatever the demonstrations say.
- Size rule L = 6 (`explicit-size:6:fewshot − fewshot`, gold): T4 −0.001 (n.s.), **T5 +0.099\*** [+0.089, +0.109].
  As predicted (+0.10 ± 0.02). The scored rule matched the offline reassembly on 99.5–99.6% of rows.
- Abstention: T4 −0.029\*, T5 −0.52\* against labelled; the calibrated threshold abstained on 54–63% of items.
  **Dropped.**
- Top-2 (secondary): T5 +0.133 over few-shot (p 0.0005); T4 +0.004.

## 3. Reading

1. **Routing is unnecessary at these frame sizes.** The simplest realistic pipeline — read with the type prior,
   recall the whole frame, no router — is within 0.02 of the labelled ceiling on both tracks. Everything RD-4c and
   RD-4d built to choose a relation was solving a problem created by a truncated evaluation.
2. **Where routing would matter** is frames long enough to crowd the context; the size rule covers it, and RD-4e's
   derived curve shows T5 accuracy rising monotonically with the whole-frame threshold up to the longest frames, so
   the break-even is beyond 8 lines if it exists.
3. **Learned relation routing does not generalise across wordings on small hosts** (0.36–0.40 on T5 with every
   demonstration scheme); word overlap (0.39) is as good. This closes RD-4d's open question negatively, and it no
   longer matters.
4. **For E13:** amendment 3's endpoint L5b, "recall only the asked relation", should be read alongside `recall:own`
   (the whole read frame), which E13 already includes. No amendment is needed; the whole-frame arm becomes the one
   to watch, and the selective arm a secondary.
5. **The remaining gap is the reader**, as before: type-prior frames give 0.72 on T4 against 0.87 with gold frames,
   and the definition text (0.734) still edges the realistic pipeline (0.719, n.s.).

## 5. What stops and what continues

- **Stops:** learned relation routers (RD-4d/4e line); abstention; the "list dilution" reading.
- **Continues:** whole-frame recall as the default explicit route in E13 and any later pipeline; the size rule only
  for frames over ~8 lines; reader precision as the open problem.
